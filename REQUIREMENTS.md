FUNCTIONS
- addition
- subtraction
- multiplication
- division

NEEDS TO
- accept two inputs
- validate inputs (must both be numerical; otherwise go to start and ask again)
- deal with errors effectively (e.g. divide by zero will return an error message to the user)
- return an completed output

EXAMPLE TERMINAL OUTPUTS (USER PROMPTS)
"Please enter your first number, as an integer (e.g. 1,2,3...)
"Please enter the operator (+ for add, - for subtract, * for multiply, / for divide)
"Please enter your second number, as an integer (e.g. 1,2,3...)
"Your result for **number1** **operator** **number2** is **result**"

EXAMPLE RESULTS FROM CALCULATIONS

5 + 5 returns 10

0 / 0 returns "ERROR: DivideByZero"
